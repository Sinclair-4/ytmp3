# YTMP3

A simple python script that allows you to download yt links as mp3 file

## Url format

```
https://www.youtube.com/watch?v=xvFZjo5PgG0
 - or -
https://www.youtube.com/watch?v=xvFZjo5PgG0&list=RDxvFZjo5PgG0&start_radio=1
```

## Setup Instructions

Follow these steps to get the project running on your machine.

### 1. Clone the repository
```bash
git clone https://github.com/Sinclair-4/ytmp3
cd ytmp3
```

### 2. Run setup
```bash
setup.bat
```
Or double click the setup file inside the project directory

### 3. Run program
```bash
ytmp3
```
After running the setup, you should be able to call this system-wide in cmd
